# 智饷系统实现状态

## 当前页面

根目录为学生与校方共用登录页，支持中央财经大学、天津大学、北京林业大学及校区选择。开发环境提供“自动填入管理员账号”按钮，仅填入账号密码；提交登录后按所选身份进入学生端或后勤端。两端退出和登录过期均返回共用入口。

学生端由 `canteen/index.html`、`app.js`、`app.css`、`themes.js` 和 `themes.css` 提供；后勤端由 `management/index.html`、`admin-script.js` 和 `styles.css` 提供。`canteen/modules/` 与 `management/modules/` 当前未被页面加载。

学生端保留主题选择、点餐、营养、食话广场、文创活动、订单和个人资料入口。导航账号与头像合为个人主页按钮。小智使用透明背景主体，支持拖动、摸头和喂餐，打开聊天时停靠到卡片左上角；九种场景形态尚未逐一接入。

## 后端与数据

独立 REST API 位于 `server/`。学校范围由认证令牌确定，管理接口验证管理员权限。后端包含菜单、订单支付核销退款、营养记录、校园活动与社区、运营台账、供需分析、任务及模型适配接口。接口能力不等于当前页面已接入全部能力。

`userdata/` 保存学校、菜单和运营初始化配置以及本地 SQLite 数据库。参考菜单 CSV 共 98 条；数据库、密钥、环境配置和日志不提交。模型参数通过后端环境配置填写。

## 验证

42 项接口回归通过。浏览器已验证管理员分别按学生与校方身份登录、退出返回统一入口、刷新保持会话、个人资料入口、导航顺序和小智聊天停靠。页面调整通过 JavaScript 语法检查与 Git 空白检查。
