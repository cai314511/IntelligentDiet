# 智饷 - 高校智慧食堂智能系统

## 项目概述

「智饷」是一个全功能的高校智慧食堂系统网站，严格遵循Apple设计语言，提供极简高端风格的用户体验。

### 核心特性
- ✅ **智能点餐系统** - 支持3个餐厅、40+菜品、多分类浏览
- ✅ **AI助手小智** - 实时对话、智能推荐、快速查询
- ✅ **营养推荐系统** - 10种健康食谱模板、个性化建议
- ✅ **社交评价平台** - 排行榜、用户评论、热菜分享
- ✅ **文化创意展厅** - 学生创作投票、文创产品、主题活动
- ✅ **完整用户系统** - 登录、个人资料、健康数据追踪
- ✅ **订单管理** - 购物车、支付、取餐码生成

## 使用指南

### 1. 首次登录
- 点击右上角"登录"按钮
- 输入任意用户名和密码（本系统使用mock数据）
- 跳转到个人资料页面
- 填写身高/体重（自动计算BMI）
- 选择健康目标
- 点击"保存资料"

### 2. 点餐流程
1. 导航栏点击"智能点餐"
2. 在顶部选择餐厅
3. 左侧菜品分类快速导航
4. 点击菜品卡片查看详情
5. 点击"加入购物车"按钮（会播放选择动画）
6. 右侧购物车显示已选菜品
7. 点击"去结算"完成订单
8. 获取取餐码

### 3. 健康推荐
1. 点击"营养推荐"
2. 查看已填写的健康资料
3. 选择健康目标（如"减肥"、"增肌"等）
4. 系统推荐对应食谱
5. 点击"加入购物车"一键添加食谱中的所有菜品

### 4. 社交评价
1. 点击"社交评价"
2. 浏览排行榜中的推荐菜品和避坑菜品
3. 浏览用户发布的评论和点评
4. 可发布个人评论
5. 提交改进建议给平台

### 5. 文化创意
1. 点击"文化创意"
2. 浏览校园文创产品
3. 投票支持学生创作
4. 查看主题菜品介绍
5. 报名参加校园活动

### 6. AI助手 (小智)
- 点击右下角蓝色圆形图标打开
- 输入问题自动获得回复
- 使用4个快速按钮快速查询
- 支持语音输入模拟

## 常见问题

### Q: 如何修改菜品价格?
A: 编辑 `data.js` 中 `dishes` 数组，修改各菜品的 `price` 字段

### Q: 如何添加新的文创产品?
A: 编辑 `data.js` 中 `culturalProducts` 数组，按照格式添加新对象

### Q: 订单数据是否会保存?
A: 目前使用完全模拟数据，页面刷新后重置。可扩展到使用localStorage持久化

### Q: 小智AI如何添加新回复?
A: 编辑 `script_v2.js` 中的 `getXiaozhiReply()` 函数，在 `responses` 对象中添加新的问答配对

### Q: 支持多语言吗?
A: 当前仅支持中文，可扩展实现国际化
