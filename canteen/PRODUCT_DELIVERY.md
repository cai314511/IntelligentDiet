## 💾 备份和恢复

### 数据备份
```bash
# 备份SQLite数据库
cp server/data/zhixiang.db server/data/zhixiang.db.backup

# 导出数据
sqlite3 server/data/zhixiang.db ".dump" > backup.sql
```

### 恢复
```bash
# 从备份恢复
cp server/data/zhixiang.db.backup server/data/zhixiang.db

# 重启应用
npm start
```
